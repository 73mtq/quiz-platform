# 国家安全教育解析核对记录

## 范围与流程

- 国家安全教育课程 290 道题，全部为 4 选项选择题，其中 60 道多选。
- 每题解析五段：正确答案、为什么对、干扰项分析、记忆、依据。
- 290 道题分 8 批起草，每批由另一轮逐题核对；主 agent 合并后用结构校验脚本检查。
- 校验脚本：`npm run validate:ns`，检查 290/290 解析、五段顺序、答案原文、干扰项覆盖、占位词、选项字母、来源登记和重复解析。

来源清单见 `content/national-security/sources.jsonl`，主要包含：

解析中的法条引用只保留能够确认的条号；无法确认的写“教材表述”，不编造条号或页码。

## 答案口径

题库答案按考试答案处理，没有擅自改动。发现题库答案与官方常见表述存在层面差异时，解析中注明，并列入下面的存疑清单。存疑题目建议结合课程教材原文核对；考试作答以题库答案为准。
